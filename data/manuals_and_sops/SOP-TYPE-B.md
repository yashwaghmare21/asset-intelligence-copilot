# Standard Operating Procedure: Type B Well (Electric Submersible Pump - ESP)
**Document ID:** SOP-ENG-TYPE-B-REV3  
**Classification:** Deep Artificial Lift & High Volume Production  
**Applicable Equipment:** ESP Downhole Centrifugal Assemblies (Series 200-299)

## 1. Operating Principle & Production Thermal Criteria
Type B wells utilize multi-stage centrifugal downhole pumps with high-voltage downhole motors. Produced fluids achieve higher flow velocities and carry significant subterranean thermal heat.

### Thermal Production Rule (Mandatory):
* **Production Status Determination:** A Type B well is classified as actively **PRODUCING** if and only if:
  $$\Delta T = T_{wellhead} - T_{ambient} \ge 18.0^\circ\text{F} \quad (10.0^\circ\text{C})$$
* **Non-Producing / Stopped Classification:**
  If $\Delta T < 18.0^\circ\text{F}$, fluid flow has ceased or the downhole motor is trip-locked. The well is classified as **STOPPED** (or **SHUT IN** if officially logged).
* **Weekly Inspection Downtime Rule:**
  Each routine weekly inspection showing $\Delta T < 18.0^\circ\text{F}$ logs exactly **7 days (1 week)** of cumulative operational downtime. Missed inspections contribute **0 days**.

## 2. Typical Operating Parameters
* Normal Wellhead Temperature Range: $95^\circ\text{F} - 145^\circ\text{F}$
* Operating Pressure: $250 - 600\text{ psi}$
* Motor Frequency: 50 to 65 Hz (VFD driven)
