# Standard Operating Procedure: Type C Well (Continuous Gas Lift)
**Document ID:** SOP-ENG-TYPE-C-REV2  
**Classification:** Pneumatic Artificial Lift  
**Applicable Equipment:** Gas Injection Mandrel Assemblies (Series 300-399)

## 1. Operating Principle & Production Thermal Criteria
Type C wells introduce high-pressure compressed gas into the annulus to aerate and reduce the density of the fluid column.

### Thermal Production Rule (Mandatory):
* **Production Status Determination:** A Type C well is classified as actively **PRODUCING** if and only if:
  $$\Delta T = T_{wellhead} - T_{ambient} \ge 12.0^\circ\text{F} \quad (6.67^\circ\text{C})$$
* **Non-Producing / Stopped Classification:**
  If $\Delta T < 12.0^\circ\text{F}$, gas aeration is ineffective or compressor supply has shut down. The well is classified as **STOPPED**.
* **Weekly Inspection Downtime Rule:**
  Each routine weekly inspection showing $\Delta T < 12.0^\circ\text{F}$ logs exactly **7 days (1 week)** of cumulative operational downtime. Missed inspections contribute **0 days**.
